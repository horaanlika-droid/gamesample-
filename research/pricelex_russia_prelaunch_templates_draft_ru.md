# Pricelex — рабочий стартовый комплект для предварительной правовой и банковской проверки

**Дата:** 28 сентября 2026 года.\
**Статус:** заполняемые внутренние шаблоны; не лицензия, не готовый договор, не заявление в Банк России и не подтверждение согласия банка. Заполнять только проверяемыми фактами. Пустые поля оставить незаполненными до получения данных.

**Куда направлять:** анкета и журнал решений — внутренние, юристу/комплаенсу проекта; запрос due diligence — юридическому или комплаенс-подразделению предполагаемого обменника; проект письма банку — только владельцу соответствующего счёта, для отправки в комплаенс этого банка; term sheet — обменнику лишь для переговоров, не для подписания до квалификации. Ни один из этих файлов сам по себе не отправлять в Банк России. Формальную заявку подаёт только допустимое российское юрлицо в установленном ЦБ порядке по актуальным № 7429-У/№ 890-П, а не самозанятый разработчик по электронной почте.

**Актуальное решение:** ИИ исключён из принятия production-решений по спорам и распоряжения депозитом; споры разбирает инициатор лично. Инициатор может доверить seed-фразу уполномоченному лицу; в формах необходимо определить фактических держателей и распределение полномочий, не запрашивая сам секрет. Seed-фразу, приватный ключ и backup никогда не записывать в эти формы, не пересылать банку/партнёру по обычной почте и не присылать в чат. Запрашиваются только адрес, сеть, тип кошелька, человеческая процедура решения и матрица полномочий.
